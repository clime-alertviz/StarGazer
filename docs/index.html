Your first evening.

1. Make it yours

Pick an avatar, share your interests and choose when you are free. Add more evenings or make it a weekly habit.

2. Find a night to join

Open suggestions appear as you plan. Check who is going, what they bring, the sky report and expected weather.

3. Check the journey

Make your own way or choose a public pickup. Review the times, choose email or Calendar, and join.

4. Keep the company

Discuss the plan on its shared page. Invite people into your circle for another evening, or organize your own.

Run the demo from the repository.

With Node.js 22.13+ and npm installed, run these commands in your checkout:

npm ci --ignore-scripts
cp .env.example .env
npm run seed
npm run web:demo

Open StarGazer at 127.0.0.1:4318. Browse the open outings, then sign in as mia@stargazer.test. Open Local outbox, follow the sign-in link and click Continue.

For a simple first join, choose I’ll make my own way. For live address search, routes and AI planning, put your Geoapify key in the ignored .env file, run npx codex login, then restart the app.

The separate sample database contains eight varied outings. For a fresh set of dates, stop the demo, run npm run seed -- --reset, then restart it. Real email and Calendar delivery need a connected provider.

Prefer to organize?

  1. Choose Plan your next adventure, complete the evening setup, then Organize my own evening.
  2. Choose your target, full availability and group size. Include the journey home and use the following date after midnight.
  3. Click Create outing. Review the proposed people, place, sky conditions and journeys.
  4. Confirm night access and the final walk. Choose circle invitations and whether remaining places are open, then invite.
  5. Follow responses on the outing page. Refresh the forecast before departure; edit or cancel when needed.

Or work entirely in Codex.

The website and the StarGazer skill share your account and outings. Local Codex can compare options, save plans and coordinate invitations through the same service.

npm run package
codex plugin marketplace add ./output/marketplace
codex plugin add star-gazer@star-gazer-local
npm run codex

First create an MCP token in the app’s Settings and add your service URL, token and Geoapify key to .env. The README explains the complete setup.
